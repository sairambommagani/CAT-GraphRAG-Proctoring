Topics that need questions (from the graph)

An NVIDIA NIM model writes questions from the topic's syllabus passage and its prerequisite topics. Each question is checked in three ways: it must be grounded in the passage, a second model call must pick the same answer, and it must not duplicate an existing question. Accepted questions become drafts for you to review.
